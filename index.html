AMCL · Adaptive Monte Carlo Localization
AMCL (Adaptive Monte Carlo Localization) is a method for estimating a robot's pose on a known map from noisy motion and sensor data. It represents the belief as a set of weighted particles: each particle is a pose hypothesis, propagated with a motion model and weighted by how well its predicted laser scan matches the real one, then resampled so likely poses survive. The particle count adapts to uncertainty (KLD-sampling): many particles when lost, few when confident, and random particles are injected when the sensor likelihood drops. It is used to localize mobile robots, such as AMRs and self-driving vehicles, on maps built with SLAM, including recovery from the kidnapped-robot problem.
